## 意图

接续 [P0027](p0027-fp8-grouped-dot-oracle.md)，补齐其参照对应的生产 C++ scalar，闭合 FP8×FP8 块缩放单输出点积的验证链，为后续 FP8 线性层与共享专家提供可复用的计算构件。成功交付是对齐既有 CPU 契约的生产入口、逐阶段 parity 及存储和环境保证，不以此宣称完整线性层、共享专家、完整 MoE 或性能提升。

## 验收

- [x] **契约承接与生产接口**：以 [COMPUTE §8](../docs/COMPUTE.md#8-fp8-块缩放单输出点积) 为唯一数值来源，继承 D0021；明确 C++ 输入、输出、失败与观测策略，沿用或最小扩展 D0009 已接受的生产方式，不新增独立数值选择。若实施发现独立新取舍，先提交用户审议，必要时另立 D，不静默外推旧决策。
- [x] **单输出生产入口**：`df_quant` 提供公共 C++ 调用，消费四份一维只读编码视图，输出为调用方提供的 FP32/BF16 原始位缓冲；公共头消费者可独立调用，成功路径无动态分配，不依赖 Python 或测试侧计算。
- [x] **数值路径与观测**：复用既有整数算术构件实现新计算链，不以旧 FP8×FP4 点积或逐元素反量化替代；普通入口与私有 trace 共用执行核心，两种输出逐阶段对照 `ref/fp8_compute.py`。有限值、零与 Inf 按位比较，NaN 按分类比较，最终输出一致不替代阶段一致。
- [x] **数值覆盖与最小组合**：复用 P0027 已有独立期望与定向向量验证新增生产路径，覆盖合法码点组合、scale 边界、相消、顺序敏感、RNE、次正规、上下溢、零符号及合法非有限结果；二维 scale 选行只在测试侧组合，既有生产激活量化的实际输出直接供新入口消费，不扩为矩阵 API。
- [x] **存储与失败保证**：两种输出覆盖长度、容量、激活及权重和两份 scale 的 NaN 编码拒绝、输入与输出的偏移重叠拒绝及精确相邻接受；元数据与别名先于内容读取，全部内容校验先于写入。拒绝时输出及观测存储不变，成功只写有效范围、输入不变；私有 trace 的尺寸与别名按实际读写范围校验，ASan 定向证明校验次序与边界。
- [x] **环境保证**：数值路径不执行宿主浮点加乘，不读写调用方浮点环境；ENV-A 八模式 MXCSR 与状态位清空/预置下，普通及观测入口的成功和拒绝均保持完整环境，核对各阶段及正式输出。
- [x] **错误检出与失败传播**：错误权重解码、二维 scale 错映射、移动/交换/合并 scale、错误归约顺序及提前 BF16 均有同例正确基线与完成调用后的数值差异；库拒绝、执行器协议失败和数值检出分开记录。执行器故障、缺依赖、响应或 trace 形状错误、结果篡改及 skip 均使新增驱动非零退出。
- [ ] **增量复现与治理**：新增生产测试接入 Debug/Release 及既有 quant ASan+UBSan scope，在 ENV-A 已提交干净检出、源码目录外复现，无 skip、构建告警或非预期报告；严格范围审计及引用检查通过。沿用旧组件验收证据，不重跑其全量套件；若修改共享 helper，仅补直接受影响的定向回归，不扩大 sanitizer scope，不设性能门槛。
- [ ] **知识与人工收尾**：实现到位后，用户人工审议实现、证据及知识处置通过；干净复现补证成立，按 D0011 单一来源归档并同步 STATUS，不以提交或合并替代验收。
