## 意图

接续已结项 [P0021](p0021-swiglu-bridge-scalar.md)，将已有激活量化、专家点积与 SwiGLU 生产组件组合为可独立调用的完整专家入口。调用方给定一个 token、一个已选 FP4 专家的三张矩阵和可选外部路由权重，生产 C++ 完成专家计算，逐阶段符合 [P0020](p0020-expert-oracle.md) 的 CPU oracle，并以一个真实专家的完整权重验证布局与数值闭环。

成功边界为单 token、单个已选专家，不扩为完整 MoE；数值契约引用 [EXPERT §1～§3](../docs/EXPERT.md#1-接口与输入)，不重新定义量化、点积或非线性语义。

## 验收

- [x] **开工前置决策**：[D0017](decisions/d0017-expert-scalar.md) 经用户审议接受，明确完整 API、独立阶段工作缓冲、共享量化、别名与校验次序；参数拒绝全存储不变，运行中 hidden 非有限拒绝允许 scratch/trace 有效前缀改写而完整 out 不变。本项据此转 active。
- [ ] **完整生产入口**：普通 C++ 消费者仅依赖公共头与 `df_quant` 即可调用。按 EXPERT §2 共享一次输入量化供 W1/W3 消费，直接调用已验收 SwiGLU，再量化 hidden 并执行 W2；公共结果为 BF16。无权重与显式权重保持既有区别，不生成或归一化权重；调用方持有工作存储，不动态分配，不复制数值核心。
- [ ] **逐阶段组合 parity**：完整入口直接对照 `ref/expert.py::expert`/`trace_expert`，核对两次量化编码与 scale、W1/W3 BF16、bridge 各阶段及 W2 全部输出，沿用既有位比较与 NaN 分类规则。覆盖单组、多组、非方阵、不同矩阵与行 scale、首末输出及两种权重入口；生产后续阶段必须消费生产前一阶段结果。普通与必要的内部观测共用执行核心，不能仅凭最终 BF16 相同认定组合正确。
- [ ] **专家级存储与失败**：依新 D 验证三矩阵形状、计数溢出、长度、容量、别名及内容错误，包括 W2 末行非法 scale；全部外部元数据先于内容读取，预检拒绝先于写入。另覆盖线性 Inf 被钳位恢复、hidden 非有限在第二次量化边界拒绝及最终 W2 非有限合法输出。检查正式输出、各工作缓冲、只读输入与范围外字节的约定状态；sanitizer 和边界探针遵守合法 C++ 对象/span 前提。
- [ ] **组合错误检出与环境**：分支接反、权重行或 scale 步长错误、遗漏第二次量化、路由权重错放、提前或绕过 BF16 落点等定向生产变体均由数值或阶段 mismatch 检出，并有同用例正确基线；异常、协议故障及存储拒绝不充当数值检出。按 BUILD 的 MXCSR 模式与初始状态覆盖普通、内部观测、接受及拒绝路径，结果环境独立且完整 MXCSR 不变。
- [ ] **真实三矩阵闭环**：固定下述专家的完整 W1/W3/W2，以确定性有限人工 BF16 输入通过本项生产入口执行，全部阶段与 P0020 oracle 对照。复用既有结构校验与有界读取，独立核对尺寸、行布局与实际载荷；离线报告可追溯环境、checkpoint 快照、源码及执行器身份、输入/载荷指纹、读取区间、命令与比较结果。缺权重、读取或执行器失败均不得 skip 或计为通过，不引入生产加载器。
- [ ] **增量复现与构建**：新增合成验证不依赖权重或网络，接入既有 Debug/Release 及适用 ASan 体系并覆盖普通消费者链接；已提交干净检出、自源码目录外复现新增验收与受实际改动影响的既有回归，无 skip、编译告警或非预期报告。既有已验收组件证据直接继承，不另立重复的 SiLU 全域证明或无差别重跑旧验收。量化提交携带有效 `Oracle:`，严格检查、范围审计及修改页引用检查通过；不设置性能门槛。
- [ ] **知识与人工收尾**：按 D0011 将完整生产契约归 EXPERT、操作与复现入口归 BUILD、验证链增量归 MODEL §4，方案理由留新 D。用户审议实现、证据和知识处置后方可结项，同步本项与 STATUS；不以组件已验收或代码合入代替本项验收。
