## 背景与问题

[P0019](../p0019-expert-linear-scalar.md) 将 P0018 的真实权重选定行消费提升为完整线性层。[D0013](d0013-act-quant-scalar.md) 仅授权 P0017 的测试内组合，尚未决定生产矩阵接口与失败语义；单输出点积的拒绝保证不能自动覆盖整个矩阵。

## 决策驱动

- 一次生产激活量化供全部输出行消费，数值仍遵循 [ACTQUANT](../../docs/ACTQUANT.md) 与 [COMPUTE](../../docs/COMPUTE.md)，不新增数值路径。
- 元数据错误和末行非法 scale 均须在写入前拒绝，输出与工作缓冲一致保持不变。
- 保持调用方拥有存储的既有接口风格，不因单 token 线性层引入通用矩阵框架或分配策略。

## 备选方案

- 新增 `df_quant` 窄接口、独立 `linear.h/linear.cpp`：采纳。扩建通用 tensor、stride 或计算图：不采纳，超过本项范围。
- 调用方提供激活编码与 scale 两份工作缓冲：采纳，容量和写入边界显式。内部动态分配或公开 workspace 类：不采纳，本项无需新增所有权框架。
- 全矩阵预检后调用现有公开量化与点积：采纳，保留已验证核心。边算边检查各行：不采纳，会产生部分输出；复制数值核心或新增未经验证的快路径：不采纳。

## 结论

2026-10-14 用户通过 P0019 开工方案审议，接受本设计并授权实施及必要的 COMPUTE/BUILD/MODEL 内容增补；不替代最终实现、证据与知识处置评审。

1. 公共入口为 `df::quant::expert_linear(input, n, w_packed, scale_b, a_codes, scale_a, out)`，位于 `include/df/quant/linear.h`，实现位于 `src/quant/linear.cpp` 并链接现有 `df_quant`。input 为只读 BF16 原始位 span，权重与权重 scale 为只读字节 span；工作缓冲为两个可写字节 span；out 分别提供 FP32/BF16 原始位 span 重载。
2. K 取 input 长度，N 由 n 显式指定。N/K 为正，K 满足既有固定分组约束；权重与 scale 长度分别严格为 `N*(K/2)` 与 `N*(K/32)`，逐行连续，不广播、不转置。w1/w3 与 w2 仅 N/K 不同。工作缓冲容量至少 K 与 K/32，输出容量至少 N，仅写有效前缀。
3. 维度、乘法与字节计数溢出、长度、容量和实际读写区间重叠检查先于任何内容读取。三个实际写入前缀互不重叠，且均与所有输入读取区间不重叠；只读输入间不禁止重叠，未使用尾部不参与判定，精确相邻允许。非法参数统一抛 `std::invalid_argument`，包括尺寸计算溢出。
4. 全矩阵权重 scale 非法编码检查在任何写入前完成；既有 act_quant 在写入前检查 BF16 有限性。所有约定拒绝均保证输出与两份工作缓冲全部不变，包括末行非法 scale。合法输入计算产生的 Inf/NaN 按 COMPUTE 处理，不视为失败。
5. 不动态分配：调用一次现有 act_quant，再逐行调用现有 expert_grouped_dot，直接消费同一工作缓冲。复用既有格式、整数舍入和输出转换，不修改底层数值契约。不新增整矩阵 trace；测试通过普通输出和工作缓冲验证生产组合。

## 后果

- D0013 保留其量化接口与 P0017 测试内组合的历史结论；本决策另行授权 P0019 新增生产矩阵组合，不整体取代 D0013，不重写其原文。
- Python 量化与逐行点积参照的组合是新算子的上一级；生产入口全向量 parity、矩阵级失败和存储、布局敏感性及浮点环境独立性须单独验收。
- P0018 入口和报告语义保持不变，P0019 另设完整 w1 离线工具，复用已有结构校验与有界读取，不引入生产加载器。
- 生产矩阵接口归 COMPUTE，操作与测试范围归 BUILD，验证链边界归 MODEL；不重复 ACTQUANT 数值规格，不承诺官方 GPU 等价、模型质量或性能。
