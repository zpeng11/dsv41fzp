## 背景与问题

[P0013](../p0013-expert-grouped-dot-scalar.md) 要交付 [COMPUTE](../../docs/COMPUTE.md) 契约的生产 C++ scalar 入口。[D0007](d0007-quant-integer-dequant.md) 只覆盖 codec 与给定 scale 反量化：它们的数值路径只有单次乘法，且合法输入的乘积不需要舍入。计算契约另有块内与跨块的 FP32 RNE 加法、合法输入产生的中间 Inf/NaN，以及逐阶段验证的需要。D0007 的结论不能直接外推，须另行决定数值路径、接口失败类与观测方式。

## 决策驱动

- 技术约束：parity 要求结果确定。宿主浮点加法受 MXCSR 舍入模式、FTZ/DAZ 与异常掩码影响；加法的输入跨越 FP32 全部指数范围，对齐移位最多可达 276 位，任意精度对齐不能照搬到单个定宽整数。
- 技术约束：中间值可以是 Inf/NaN，而 `detail::multiply_finite` 只接受有限操作数。
- 项目约束：scalar 是快路径的上一级参照，不承担性能论断；`df_quant` 已有的只读视图、调用方输出缓冲与标准异常约定保持一致；不新增公共软件浮点 API，也不建第二个格式或舍入中心。

## 备选方案

### 数值路径

- 整数位运算构造全部阶段，含加法：结果与调用环境无关，环境验证沿用 D0007 的矩阵方法，不需要环境检查及其失败类：采纳（用户已于 P0013 设计讨论中拍板）。
- 宿主 FP32 加法加调用时 MXCSR 检查或调用内设置并恢复：否决理由与 D0006/D0007 相同；而且加法需要舍入，宿主结果受环境影响的面比乘法更大。

### 加法的有效数表示

- 定宽对齐加 sticky：较小操作数右移，移出的位折叠为一位 sticky，至少保留两个 guard 位后，交给既有的 `binary_to_fp32` 舍入构造（提到 `detail` 后复用）：采纳，推荐。只需一个舍入器，敏感性注入与专项 parity 都只针对它。
- 足够宽的固定多字精确表示：正确，但位宽在 300 位上下，还要另写舍入：不采纳，除非 sticky 方案的专项 parity 暴露无法修正的问题。

### 逐阶段观测

- 一个 `detail` 核心函数接收可空的 trace 接收器，公开入口传空：两种入口执行同一份编译代码，"观测不改变计算"可由公开入口与观测结果逐位一致直接证明；scalar 不是快路径，分支开销无关紧要：采纳，推荐。
- 核心按观测器模板化，公开入口用空观测器实例化：零开销，但公开路径与观测路径是两次实例化，"同一执行路径"需额外论证：不采纳。
- 测试专用点积或把 trace 纳入公共 API：违反 COMPUTE §4 同路径要求或扩大公共接口：否决。

### 接口与失败类

- 沿用 D0007 结论 1～3：只读 `std::span<const uint8_t>` 视图、FP32/BF16 原始位模式的输出 span 重载、`std::invalid_argument`、元数据先于内容、内容先于写入、失败时输出不变、拒绝输入与输出重叠：采纳。单输出入口只写一个元素，保留 span 是为了与既有入口的调用方存储与失败约定一致，不预先承诺多输出。
- K 取激活视图长度，长度换算只有 K/2、K/32，不存在元数据乘法，因此本入口没有 `std::overflow_error` 拒绝类。这是 D0007 结论 2 在本入口不适用的部分，不是偏离；不为此伪造测试。
- K=0 拒绝，跟随 COMPUTE §2；与 QUANT 反量化接受零元素张量的约定有意不同，归档时须写明。

## 结论

2026-10-12 经用户确认接受，同时确认 P0013 当前范围：

1. 生产计算路径全部阶段以定宽整数位运算构造：有限乘法复用 `detail::multiply_finite`，非有限操作数先按 COMPUTE §3 分流；加法采用定宽对齐加 sticky，复用既有舍入构造；不执行浮点运算，不读写浮点环境。
2. 接口与失败类按上节"接口与失败类"的采纳项。
3. 逐阶段观测采用可空 trace 接收器的单一 `detail` 核心；执行器经私有头连接，trace 不进入公共 API。

## 后果

- 扩展而不取代 D0007；D0007 的适用范围不变。SIMD/CUDA 等快路径若使用宿主或设备浮点运算，其环境与失败策略须另立决策，parity 对照本 scalar。
- 接口、失败与环境契约归档 COMPUTE，测试入口归档 BUILD；加法的位宽、移位上界与 guard/round/sticky 处理写在 helper 的函数级注释中，本条目只保留选择理由。
- P0013 的数值路径、观测连接与加法验收以本条目为依据；本条目被接受前，P0013 不进入 active。
