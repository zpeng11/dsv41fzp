## 意图

接续 [P0025](p0025-routed-branch-oracle.md)，把 [P0024](p0024-router-scalar.md) 的生产 router 与 [P0022](p0022-expert-scalar.md) 的完整 FP4 专家组合为单次生产调用，闭合单 token 主干 routed 分支。成功交付是对齐既有参照的 FP32 routed 部分和及组合层的存储、失败保证，不以此宣称完整 MoE 或性能提升。

## 验收

- [x] **生产接口与契约**：在 MOE 补充生产接口、调用方工作区、完整专家表、预检/别名及失败/环境保证，沿用既有数值语义；本项继承 D0020 及用户已审议设计，不新增独立数值选择。
- [x] **生产入口**：`df_core` 的单次公共调用完成 MOE §1～§3 的 routed 计算，复用既有生产 router、weighted expert 与整数 FP32 加法，交付 FP32 raw-bit 输出；不依赖 Python 或测试侧串接，不新增动态数值存储。
- [x] **真实组合 parity**：普通与私有观测共用执行核心，直接对照 `ref/moe.py`；文本/图像选择及不同专家三矩阵的合成调用核对实际编号/权重接线、执行次序、每步部分和与最终输出，不以单专家衔接或最终偶合代替组合验收。
- [x] **聚合边界与错误检出**：复用 P0025 独立期望，覆盖新增聚合层的舍入、抵消、零、次正规及合法非有限结果；错误专家/权重接线、错误累加顺序、重复施加权重、提前 BF16 转换及非逐步 FP32 舍入有同例正确基线和完成调用后的数值反例。定向注入的聚合证据与真实组合证据分开记录，异常或协议失败不计数值检出。
- [x] **存储与失败**：全部专家（含未选专家）的计算前校验、尺寸/容量/别名、只读及写范围外不变均有定向证据；参数拒绝保持全部存储不变，router 或后续专家运行失败不交付部分正式输出，私有观测仅成功后交付。
- [x] **公共消费与环境**：公共头消费者可独立调用生产入口；成功、观测、参数拒绝及运行失败覆盖 BUILD 约定的 MXCSR 控制模式与状态初值，验证生产入口的环境保证及输出尾部不写。
- [ ] **增量复现**：ENV-A 已提交干净检出、源码目录外的 Debug/Release 与受影响 sanitizer scope 中，新增及实质受影响的测试通过，无 skip、构建告警或非预期报告；严格检查、提交范围审计及修改页引用通过。沿用已通过的旧组件证据，不重复全量验收，不设性能门槛。
