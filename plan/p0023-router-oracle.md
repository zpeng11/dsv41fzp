## 意图

接续已结项 [P0022](p0022-expert-scalar.md)，补齐完整 FP4 专家入口上游的专家选择与权重生成。以单 token 激活和模型 gate 参数为输入，建立覆盖 gate 投影、打分、选择及归一化的 CPU 慢参照，为后续生产 router 提供独立验证的上一级。

成功边界为从单 token 激活得到有独立数值依据的专家编号与 FP32 路由权重，不止于给定分数后的 top-k；不实现完整 MoE。模型参数引用 [MODEL §1](../docs/MODEL.md#1-概览) 与 [§3.5](../docs/MODEL.md#35-路由srccore)，不另建通用路由配置体系。

## 验收

- [x] **开工前置决策**：[D0018](decisions/d0018-router-reference.md) 经用户审议接受，本项转 active；明确 gate 累加与舍入、softplus/sqrt 阶段、top-k 平局和返回顺序、权重归约、失败及环境边界，不套用专家点积或推定官方 GPU 规则。
- [ ] **完整 Gate 参照**：新增单 token Python 入口，消费 BF16 激活、模型 gate 权重及 FP32 选择 bias，完成拓宽后的 FP32 线性、模型温度步骤、softplus、sqrt、加 bias 选择、从未加 bias 分数取权重、被选专家内归一化及路由缩放。支持文本与图像 token 的 bias 选择；普通与 trace 共用核心，输出编号与 FP32 权重的明确编码，输入不变。不新增生产 router 或通用线性代数框架。
- [ ] **逐阶段独立验证**：以独立精确算术或认证区间建立投影、非线性、选择及权重的期望链，不调用被测数值 helper，不直接用 Torch/libm 输出充当真值。对全部返回编号、权重和约定 trace 阶段逐项比较；期望的后续阶段消费期望的前阶段结果，不以最终编号或权重偶合代替阶段验证。
- [ ] **边界与失败**：覆盖投影抵消及累加次序敏感输入、非线性极端值与舍入边界、top-k 截止处近邻和平局、bias 改变选择但不参与权重、文本/图像 bias 分支、归一化防零与下溢。覆盖形状、长度、编码及内容拒绝，按新 D 检查输入不变、失败传播及普通/trace/拒绝路径的环境保证；不以随机样本替代定向边界。
- [ ] **错误检出**：偏置进入权重、归一化与选择次序错误、权重取错专家、遗漏或错误缩放，以及违背已定投影/舍入/top-k 规则的定向错误链，均由指定用例的编号或阶段数值 mismatch 检出，并有同用例正确基线；异常、协议故障或参数拒绝不充当数值检出。
- [ ] **专家接口衔接**：少量无权重文件的合成用例将生成的专家编号与 FP32 权重接入既有 `ref/expert.py` 和 P0022 生产专家执行器，核对所选矩阵、权重对应关系及专家结果。复用既有专家契约和验证入口，不修改其数值语义，不新增多专家调度或聚合入口，不据此认定完整 MoE 已验收。
- [ ] **增量复现**：新增验证限 BUILD 的 ENV-A，使用 Python 标准库、无需 GPU、网络或 checkpoint，提供源码目录外可执行命令并接入 Debug/Release CTest。已提交干净检出复现本项及受实际改动影响的回归，无 skip 或非预期报告；严格检查、提交范围审计与修改页引用检查通过。继承 P0022 及既有组件证据，不无差别重跑旧验收，不设置性能门槛。
